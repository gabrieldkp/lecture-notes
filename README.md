# 강의노트

아이패드에서 수업 슬라이드(PDF)를 보면서 필기하고, 녹음과 실시간 자막을 함께 남기는 웹앱입니다.
Safari에서 열고 **공유 → 홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 지금 되는 것

- 강의 목록: 만들기, 삭제
- 슬라이드 PDF 불러오기 (PPT는 PowerPoint/Keynote에서 PDF로 내보낸 뒤 불러오기)
- 슬라이드를 위아래로 이어서 보기, 슬라이드 위 필기: 펜(색 4개), 형광펜, 지우개, 되돌리기. 애플펜슬로만 그려지고 손가락은 스크롤 ("손가락 필기"를 켜면 손가락으로도 필기)
- 오른쪽(세로 모드에선 아래) 패널: 위 절반은 전사, 아래 절반은 타이핑 노트. 녹음 중이면 그 시각과 슬라이드 번호가 같이 저장됨
- 녹음: 일시정지/계속, 끝낸 뒤 "이어서 녹음", 5분마다 자동 저장, 녹음 중 화면 꺼짐 방지, 마이크 소리 물결 표시
- 녹음 끊김 대비: 화면을 잠그거나 다른 앱에 갔다가 돌아왔을 때 녹음이 끊겼으면 알려주고 바로 이어서 녹음. 3초마다 마이크 상태를 확인해 끊기면 자동으로 다시 연결
- 긴 수업 대비: 슬라이드는 화면 근처 페이지만 그려서 50쪽짜리 PDF도 메모리를 적게 씀
- 실시간 한국어 자막 (Safari 음성 인식, 기본 켜짐. 끄면 그 설정을 기억)
- 다시 듣기: 노트의 ▶ 시각, 자막 줄, "▶ 필기 눌러 듣기" 도구로 필기를 누르면 그때 녹음 재생. "재생 따라가기"를 켜면 재생 위치에 맞춰 슬라이드가 넘어가고, 아직 안 쓴 필기는 흐리게 보였다가 그 시점에 진하게 나타남
- 녹음 파일 내보내기: 원본 녹음을 공유 시트로 보내기 (클로바노트 등에서 더 정확하게 다시 전사할 때)
- 요약용 전체 복사: 전사문과 노트를 슬라이드별로 정리해 복사 → Claude 앱에 붙여넣어 요약 (요약 API 연결 전 임시 방법)

모든 데이터는 아이패드 안(브라우저 저장소)에만 저장됩니다. 서버로 보내는 건 없어요.
단, 홈 화면에 추가하지 않고 Safari에서만 쓰면 오래 안 열었을 때 Safari가 데이터를 지울 수 있으니 꼭 홈 화면에 추가해서 쓰세요.

## 구조

```
index.html            화면 틀
style.css             디자인
js/app.js             시작점, 강의 목록
js/lecture.js         강의 화면 (슬라이드, 노트, 전사, 녹음 연결)
js/pages.js            위아래로 이어지는 슬라이드 화면
js/ink.js             필기 레이어
js/player.js           여러 녹음 구간 이어서 재생
js/art.js              캐릭터 그림 (까망이, 알렉스, 발바닥)
js/recorder.js        녹음, 실시간 자막
js/db.js              아이패드 안 저장소 (IndexedDB)
sw.js                 오프라인 동작
vendor/pdfjs/         PDF 뷰어 라이브러리 (pdf.js 4.10.38, Apache-2.0)
```

빌드 과정이 없는 순수 HTML/JS라서, 파일을 그대로 웹에 올리면 바로 동작합니다.

## 내 컴퓨터에서 실행해 보기

```
python -m http.server 8000
```

후 브라우저에서 http://localhost:8000 을 엽니다. 아이패드에서 녹음하려면 https 주소가 필요해서, 실제 사용은 GitHub Pages에 올려서 합니다.
